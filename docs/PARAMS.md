# Program parameters

| Item | Detail |
|---|---|
| Table | `engine/src/control/params_table.inc`, generated by `tools/gen_params.py` from the Prophecy Parameter Guide (6.6 MIDI Implementation, Program Parameters). Public documentation, no firmware data |
| Count | 525 parameters: program common, EG1-4, LFO1-4, oscillator common, OSC1/OSC2, sub/noise, wave shape, mixer, filters, amps, amp EG, distortion, wah, chorus/delay/reverb, EQ, output, and the oscillator-model parameters per slot (Standard, Comb, VPM, Modulation for OSC1/OSC2; Brass, Reed, Pluck for OSC1) |
| Not included | Program name/category and controller assignment (V55-only: they never reach the H8; MIDI CCs and Q-Links replace them), reserved bytes. The Performance Editor is V55-only too and is reimplemented: see below |
| Layout check | Every offset and bitfield equals the H8 firmware's own parameter table (korgpro20: entries at 0x0EB0A + 10 * id = {u16 offset, u16 shift << 8 \| width - 1, u32 handler, u16}) |
| Documentation errors found | Chorus Depth Mod Intensity (360) is signed -99..+99 (guide: 0~99); Scale Type is 0..10 (11 scales; the dump table says 0~15); Reed Noise Level is 496 (record byte 190), not 498 (byte 192 holds a signed hidden value); Reed hidden bytes exist between the listed parameters |

## How an edit reaches the engine (measured on the oracle)

| Edit | V55 -> H8 | Tool |
|---|---|---|
| Any program parameter | `40 hh ll vv`: hh = ExID << 4 \| id >> 8, ll = id & 0xff, vv = raw value byte (two's complement) | `reference/wsl/param_sweep.py` |
| Oscillator-model parameter of an inactive model | nothing (dropped) | same |
| OSC Set (154) | the whole program record (`50 01 b3` + 435 bytes) with each slot whose model changed reset to the V55's defaults for that model, then the current controllers | `reference/wsl/probe_oscsets.py` |
| Name, category, controller assignment, Performance Editor | not sent / V55-internal | `param_sweep.py` |
| Key transpose (global) | `90 vv` | `GROUP=0 param_sweep.py` |
| Program change | the program burst, built by the engine from the program's dump (`Synth::build_burst`): controller resets; the previous program's Wheel1/2/3+/3- and Ribbon X/Z controllers to 0; the record; the new program's wheels at their panel positions (Wheel1 0, Wheel2 0x4040, Wheel3 0x4040 or each half 0) and Porta SW; every Performance Editor assignment as a `40` edit of its current value | `engine/test/program_test`: all 128 factory bursts byte-equal to the oracle's captures; program 8 -> 1 equal to the oracle's |
| Current Program Data Dump (SysEx, 619 bytes) | the record, then the wheel / CC91-95 / Porta block of an OSC Set reload, then the PE assignments (no program-change resets); the record and PE part equal the engine's | `probe_pe.py` with `program_test --syx` |
| Note off | `00 nn vv` with the MIDI release velocity (note-on velocity 0: vv = 0) | `reference/wsl/probe_pe.py` |

Model defaults: 7 x 34 bytes in the V55 ROM (korgpro20 ic12 0x3C587: Standard, Comb, VPM, Modulation, Brass, Reed, Pluck), matched byte for byte against the oracle's OSC Set records; read from your `ic12.bin` at load.

## Performance Editor

The five PE knobs and four PE sets (`engine/src/control/perf.h`), reimplemented from the V55's behaviour (its knob routine traced on the oracle, see [V55.md](V55.md)) and checked value for value against it.

| Item | Detail |
|---|---|
| Per program | 4 sets x 5 knobs x {PE parameter number, value at knob 0 (% of range), value at knob 127 (%), curve 0 linear / 1 exp / 2 log}, PE1-4 on/off, 5 stored knob positions: the 535-byte dump's bytes 444..529, read from the factory programs in your `ic12.bin` (korgpro20 0x3FF60), or from your SysEx files |
| PE parameter numbers | Parameter Guide 6.4 assign list (`tools/pe_assign.py` -> `kPeAssign`), equal to the V55's own table except #250 (Reed Noise Level = 496) |
| End values | lo + pct * (hi - lo + 1) / 100, at most hi (C integer division; the V55's range table equals ours) |
| Curve | 128-entry table in the V55 ROM (korgpro20 ic12 0x77676), read from your `ic12.bin`; exp = 127 - t[127 - x], log = t[x] |
| Knob -> value | integer steps over 128 knob positions; an odd span wider than 128 is split at knob 64 (`pe::interp`); knob 0 / 127 give the end values |
| Applied | per switched-on set (a later set assigned to the same parameter wins), if the PE number is valid for OSC Set and Delay/Reverb select and the value differs from the current one; edits go out as `40` messages. The V55 reads the Modulation type for this check through its panel's edit context (OSC1 after power-on and program changes), i.e. record byte 172; reproduced |
| Also sent | the knob as controller `30 23+k` (CC19..23); MIDI CC19..23 are the knobs |
| PE switches | gate later knob moves only (switching a set on applies nothing) |
| NRPN (guide 2-1) | 00 01..00 05 arpeggiator, 00 06..00 09 PE1-4: data entry CC6 (still forwarded as controller 0x16), increment/decrement CC96/97 (switch: on/off); CC96..101 are not forwarded; an RPN selection deselects the NRPN |

| Check | Result (korgpro20) |
|---|---|
| `reference/wsl/pe_expect.py` -> `engine/test/pe_test` | 256 knob moves over all 128 factory programs (467 edits): all equal to the oracle; PE switches, NRPN, position restore |
| `reference/wsl/probe_pe.py` | single probes (switch toggles, NRPN/RPN, curves, the odd-span split) |

## Global settings (measured on the oracle: Global PARAMETER CHANGE, group 0)

| Global parameter | V55 -> H8 |
|---|---|
| Master Tune (1) | `80 vv`, vv = (Hz - 440) * 10 as a signed byte (not clamped by the V55) |
| Key Transpose (2) | `90 vv` |
| Velocity Curve (3), After Touch Curve (4), After Touch Sense (5) | nothing: they shape the Prophecy's own keyboard only; MIDI note velocity and channel aftertouch reach the H8 unchanged |
| Transpose Position (9) | `a0 vv` |
| DelayReverb (13) | `c0 01` on, `c0 00` bypass |
| User Scale 1 (14-25) / 2 (26-153) | `b0 tt kk vv`: tt 0 / 1, kk key, vv cents (signed) |
| Knob1-5 Controller (172-176) | on MIDI input a CC turns every knob assigned to it (after being forwarded once); aftertouch moves its knobs to the first step of the V55's 4-step aftertouch ramp; pitch bend moves none; reassigning resets the knob's old CC (`30 id 00 00`) |
| Arpeggiator Velocity / Gate Controller (177 / 178) | no message: the V55 scales each arpeggio step (`engine/src/arp.h`; its step routine, ROM 0xB3600) |
| At boot the V55 sends | `80 00`, `90 00`, `a0 00`, `c0 01`, then User Scale 1 and 2 all 0 (the plugin's defaults) |

`engine/test/param_test` checks the H8 acts on them: Master Tune 450.0 Hz raises A21 by +37.9 cents (450/440 = +38.9), User Scale 1 +100 cents on A by +92.2 cents (mean pitch over 3 s; the program's slow pitch movement moves it a few cents), Delay/Reverb bypass silences A00's effect tail.
