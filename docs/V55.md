# V55 (panel / MIDI CPU, ic12) notes

The V55 never runs in the plugin: what it does to MIDI, the panel and the Performance Editor is reimplemented natively and checked against the oracle. This page records where the behaviour was found (korgpro20, v2.0) so it can be re-checked. Addresses are V55 physical addresses; ROM offset = address - 0x80000.

## Address map

| Item | Detail |
|---|---|
| ROM | 0x80000-0xFFFFF (512 KiB) |
| DS | 0xF5EE: DS offsets 0x0000-0xA11F are ROM constants (0xF5EE0-0xFFFFF), 0xA120-0xFFFF wrap to RAM 0x00000-0x05EDF |
| Edit context | DS:0xD87A low byte: the oscillator a slot-less model parameter id refers to (0 = OSC1 at power-on and after program changes) |
| Parameter range table | DS:0xAE88 (RAM 0x00D68), 6 bytes per id: hi (u8), lo (s8), ...; equals our `kDefs` ranges (after the Scale Type and Reed Noise fixes) |
| Parameter offset table | CS 0xB89F, offset 0xF2 + 8 * id: {u16 record offset, ...}; ExID adds 0 / 172 / 220 (CS:0x151A) |
| PE assign table | ROM 0x7E0F8, 6-byte entries, PE number -> parameter id (= `tools/pe_assign.py`) |
| PE curve table | ROM 0x77676 (DS:0x1796), 128 signed bytes |
| Factory programs | ROM 0x3FF60, 128 x 535-byte dumps |
| Arpeggio patterns | ROM 0x3E542, 10 x 128 bytes (UP, DOWN, ALT1, ALT2, RANDOM, PAT1-5) |
| Oscillator-model defaults | ROM 0x3C587, 7 x 34 bytes |

## Routines

| Address | What | Ported to |
|---|---|---|
| 0xA9F4E | PE knob moved (value, knob parameter 0x27B..0x27F): end values, curve, interpolation, set precedence, validity, apply | `engine/src/control/perf.cpp` `pe::knob` |
| 0xAA330 | PE curve (0 linear, 1 exp, 2 log) | `pe::curve` |
| 0xA37A7 | PE interpolation (odd span > 128 split at knob 64) | `pe::interp` |
| 0xA3A60 | PE number valid for OSC Set / Delay-Reverb select / MOD type | `pe::valid` |
| 0xABC36 | parameter get (slot-less model ids use the edit context) | - |
| 0xB9F14 / 0xB9FDB | parameter read / write in the edit buffer | - |
| 0xAF686 / 0xAF695 / 0xAF734 | long divide (signed) / long modulo / long multiply (C runtime) | C integer arithmetic |
| 0xB35CE | arpeggio step (hand-written): slot choice, Velocity / Gate Controller scaling, same-note merge, note-on, gate time | `engine/src/arp.cpp` `Arp::controllers`, `advance` |
